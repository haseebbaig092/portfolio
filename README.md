# Cornice

Cornice is a fast, flexible Shopify Online Store 2.0 theme for fashion, gifts, beauty and general retail stores. It is built with plain Liquid, CSS and a small amount of JavaScript. It has no third-party libraries and no build step, so every file in the theme can be read and edited.

**Version:** 1.0.0
**Author:** Shining Stars
**Requires:** Shopify Online Store 2.0

## Highlights

- 6 color schemes you can apply to any section
- 3 header layouts, with a sticky bar or a floating pill
- Mega menu with a glass or solid dropdown

## Installation

### From the Shopify Theme Store

1. In your Shopify admin go to **Online Store > Themes**.
2. Find Cornice in the Theme Store and select **Add theme**.
3. Select **Customize** to open the theme editor.

### From a ZIP file

1. Go to **Online Store > Themes**.
2. Select **Add theme > Upload zip file**.
3. Choose the Cornice ZIP file and select **Upload**.
4. Select **Customize** to open the theme editor.

## Quick start

Do these in order for the fastest setup.

1. **Set your brand.** Open **Theme settings** (the paintbrush icon). Choose your fonts under **Typography**, your colors under **Colors**, and your corner rounding under **Border radius**.
2. **Add your logo.** Open the **Header** section and upload a logo. Set the desktop and mobile logo width.
3. **Build your menu.** In Shopify admin go to **Content > Menus**, create a main menu, then pick it in the Header section.
4. **Build the home page.** Add sections from the **Add section** list. Reorder them by dragging.
5. **Set up filters.** Install the free **Shopify Search & Discovery** app and choose the filters you want. See [Collection page and filters](#collection-page-and-filters).
6. **Choose how the cart behaves.** In **Theme settings > Cart**, pick the cart page or the cart drawer.
7. **Add social links.** In **Theme settings > Social media**, paste your profile links.

## Theme settings

Open **Customize > Theme settings**. These settings apply to the whole store.

| Group | What it controls |
| --- | --- |
| Colors | Six color schemes. Each scheme sets background, text, heading, button, link, icon and border colors, and can use a gradient background. |
| Border radius | Corner rounding for images, buttons, cards, inputs, badges, dropdowns, the sticky header pill and swatches. |
| Card variant options | How color swatches and size options look on product cards. |
| Typography | Fonts, sizes, weights and letter spacing for headings, subheadings, eyebrows, body text, navigation and buttons. |
| Cart | Cart page or drawer, order notes, vendor display, sticky checkout button, and the empty cart message. |
| Search | Turns predictive search on or off. |
| Favicon | The small icon in the browser tab. |
| Social media | Instagram, Facebook, X (Twitter), TikTok, YouTube and Pinterest links. |
| Motion | Animation speed, card hover effects, entrance animations, image hover, button and link hover, slideshow transition, marquee speed and direction, and a reduced motion option. |

### Color schemes

Every section has a **Color scheme** setting. Schemes 1 to 6 are light, dark, subtle, cream, stone and charcoal by default. Change any color in Theme settings and every section using that scheme updates.

### Corner rounding

The border radius setting for buttons is also used for inputs, newsletter fields and the language and country selectors, so every control in the theme matches. The **Header pill** radius only affects the floating sticky header.

## Header and navigation

Open the **Header** section in the header group.

### Layout

| Option | Description |
| --- | --- |
| Logo center, menu left | Logo in the middle, menu on the left, icons on the right. |
| Logo left, menu center | Logo on the left, menu in the middle, icons on the right. |
| Logo center, menu below | Logo in the middle, menu on a second row. Social icons can show on the left. |

### Header style

- **Solid.** The header has its own background.
- **Transparent.** The header sits over the first section, such as a slideshow, and turns solid when the page is scrolled.

### Sticky

| Setting | Options |
| --- | --- |
| Sticky header | Off, Always visible, Show on scroll up |
| Sticky header style | Full width bar, Floating pill |
| Shrink on scroll | On or off |

The floating pill uses the **Header pill** radius from Theme settings. With the **Logo center, menu below** layout, the menu moves into the logo position when the pill is active.

### Menu block

Add a **Menu** block for each mega menu. Mega panels can show links, images and featured products. The **Dropdown background** can be solid or glass.

### Other header options

Logo width (desktop and mobile), header border, navigation item spacing, search icon, cart icon, social icons in the mobile menu, dropdown width, page width, and top and bottom padding.

### Announcement bar

Add an **Announcement bar** section above the header for shipping messages and promotions. Add several announcements and they will rotate. Each can have its own link.

## Collection page and filters

Cornice uses **native Shopify filtering**. It does not add a custom filter system.

1. Install the free **Shopify Search & Discovery** app.
2. Open **Filters** in the app and add the filters you want (availability, price, product type, vendor, color, size, and so on).
3. The filters appear on collection and search pages automatically.

In the **Collection** section you can turn filters on or off, choose the filter style, set the products per page and the columns on desktop and mobile, and show a grid density toggle. For pagination choose page numbers, a load more button or infinite scroll. Card style, text alignment, image ratio, badges, swatches and the add to cart button are also set here.

Filter and sort changes update the page without a full reload.

| Block | Description |
| --- | --- |

| Breadcrumbs | Path back to the collection. |
| Vendor | Brand name. |
| Heading | Product title. |
| SKU and inventory | SKU and stock status. |
| Rating | Star rating from your reviews app. |
| Price | Price, compare-at price, sale badge and unit price. |
| Variant picker | Buttons, dropdowns and color swatches. |
| Quantity selector | Quantity input. |
| Buy buttons | Add to cart and Shopify dynamic checkout buttons. |
| Pickup availability | In-store pickup information. |
| Trust badges | Short reassurance items, such as fast shipping or easy returns, shown under the buy buttons. Edit the icon, label and text of each. |

### Size guide

Turn on **Enable size guide** in the product information section and choose a **Size guide page**. The page content opens in a modal.

A second product template named **product.pre-order** is included. Assign it to products that are sold before they are in stock.

### Apps

The page supports Shopify app blocks. Add them from **Add block > Apps**.

## Cart

Choose the behavior in **Theme settings > Cart**.

- **Go to cart page.** The customer is sent to the cart page after adding a product.
- **Open cart drawer.** A drawer slides in from the side.

Both versions can show order notes, vendors and a sticky checkout button. In the **Cart drawer** section you can add text blocks and a featured product block. Add the **Cart recommendations** section to the cart page to show suggested collections.

## Translations

Cornice is ready for translation. All text shown to customers comes from the locale file `locales/en.default.json`.

- To translate your store, use **Settings > Languages** in Shopify admin and select **Edit theme content** for each language.
- Text you type into the theme editor, such as headings and button labels, is translated with the same tool.

## Performance and accessibility

- Images use responsive `srcset` and `sizes`. Only the first image on the page loads with high priority. Other images load lazily.
- JavaScript is split by page. The collection filters, the product page code and the cart code load only where they are needed.
- There are no external fonts or libraries added by the theme. Fonts come from Shopify's font library.
- Animations respect the visitor's reduced motion setting. You can also turn them off in **Theme settings > Motion**.
- Menus, dropdowns, drawers, modals, accordions and sliders work with the keyboard and have visible focus outlines.
- Interactive elements have text labels or ARIA labels for screen readers.

## Frequently asked questions

**The filters do not show on my collection page.**
Install the free Shopify Search & Discovery app and add filters in its **Filters** page. Cornice shows what the app provides.

**How do I change the logo size?**
Open the Header section and change **Logo width (desktop)** and **Logo width (mobile)**.

**How do I make the header float as a pill?**
In the Header section, set **Sticky header** to Always visible or Show on scroll up, then set **Sticky header style** to Floating pill. Change its corner rounding under **Theme settings > Border radius > Header pill**.

**How do I turn off the slideshow auto slide?**
Open the Slideshow section and set **Auto slide** to Off.

**Can I add my own code?**
Yes. Use the **Custom liquid** section, or add an app block.

**How do I change the cart to a drawer?**
Open **Theme settings > Cart** and set **Cart behavior** to Open cart drawer.

**My product images look cropped.**
Check the image ratio in the product gallery block and in the card options of the section. Choose **Natural** to keep the original shape where that option is offered.
